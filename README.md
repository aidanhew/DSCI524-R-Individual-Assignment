
# fibonacci

The goal of fibonacci is to list fibonacci numbers up to a specified
integer

## Installation

You can install the development version of fibonacci from
[GitHub](https://github.com/) with:

``` r
# install.packages("devtools")
devtools::install_github("aidanhew/DSCI524-R-Individual-Assignment")
```

## Example

This is a basic example which shows you how to return fibonacci numbers
up to 10:

``` r
library(fibonacci)

fib_before_n(10)
#> [1] 0 1 1 2 3 5 8
```
